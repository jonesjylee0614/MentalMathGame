# 种植模式 (Farming Mode)

## 📝 概述

种植模式是一个以植物生长为主题的游戏模式，让玩家通过答题来照顾植物，看着它们从种子🌱成长为美丽的鲜花🌺。

## 🎮 游戏玩法

### 答对题目
- 植物生长到下一个阶段
- 出现阳光☀️和闪光✨特效
- 显示鼓励性消息
- 花园进度增加

### 答错题目
- 害虫🐛出现在花园中
- 需要继续答对题目来驱赶害虫
- 害虫会在1.5秒后自动离开

## 🌱 生长阶段

植物有5个生长阶段：

1. **种子** 🌱 - 刚刚种下
2. **发芽** 🌿 - 开始生长
3. **幼苗** 🪴 - 茁壮成长
4. **开花** 🌻 - 即将盛开
5. **盛开** 🌺 - 完全绽放

每个阶段需要答对一定数量的题目才能升级。

## 🎨 视觉元素

- **背景**：从天空蓝到草地绿的渐变
- **主植物**：中央显示当前阶段的植物
- **背景花园**：已经长出的花朵装饰
- **进度条**：显示花园完成度
- **阶段指示器**：显示所有生长阶段的进度
- **特效**：
  - 答对时：阳光光芒、闪光特效
  - 答错时：害虫爬行动画

## 📋 适用题型

根据设计文档，种植模式特别适合：
- ✅ 乘法口诀（需要重复练习）
- ✅ 表内除法（需要持续练习）
- ✅ 长时间关卡（30+题）

## 🔧 技术实现

### 文件结构

```
frontend/src/
├── lib/gameModes/modes/
│   └── FarmingMode.ts           # 模式逻辑
├── components/gameModes/
│   └── FarmingModeComponent.tsx # React组件
└── styles/gameModes/
    └── FarmingMode.module.css   # 样式文件
```

### 状态管理

```typescript
{
  currentStage: 0,              // 当前生长阶段（0-4）
  correctCount: 0,              // 答对题目数
  totalQuestions: 0,            // 总题目数
  plants: [],                   // 背景花朵数组
  bugs: [],                     // 害虫数组
  showGrow: false,              // 显示生长动画
  showBug: false,               // 显示害虫警告
  showSun: false,               // 显示阳光特效
  encouragingMsg: '',           // 鼓励消息
  lastActionCorrect: null       // 最后一次操作是否正确
}
```

### 事件系统

模式发射的自定义事件：
- `plantGrow` - 植物生长
- `newPlantBloomed` - 新花朵绽放
- `bugAppeared` - 害虫出现
- `bugLeft` - 害虫离开
- `gardenComplete` - 花园完成

## 💡 使用方法

### 在关卡中配置

在 `frontend/src/lib/levels.ts` 中为关卡指定 `farming` 模式：

```typescript
{
  id: 'mul_6',
  category: '进阶拓展',
  name: '6以内的乘法口诀',
  desc: '2~6 乘法表',
  generator: { type: 'mulTable', maxTable: 6 },
  count: 30,
  timeSec: 120,
  difficulty: 1.6,
  gameMode: 'farming',  // 指定种植模式
  modeConfig: {}        // 模式特定配置（可选）
}
```

### 已配置的关卡

目前以下关卡使用种植模式：
- `mul_6` - 6以内的乘法口诀
- `mul_9` - 9以内的乘法口诀
- `div_6` - 6以内的表内除法
- `div_9` - 9以内的表内除法

## 🎯 设计亮点

1. **渐进式成就感**：植物的5个生长阶段提供持续的成就感
2. **视觉反馈丰富**：答对有阳光和闪光，答错有害虫
3. **非惩罚性错误**：答错不会让植物退化，只是出现可驱赶的害虫
4. **适合长关卡**：30+题的关卡不会感觉枯燥，因为可以看到植物逐渐成长
5. **教育意义**：与"照顾植物"的隐喻结合，培养耐心和坚持

## 📊 性能优化

- 使用CSS动画（GPU加速）
- 及时清理定时器防止内存泄漏
- 合理控制背景花朵和害虫的数量
- 使用CSS Modules避免样式冲突

## 🐛 已知限制

- 害虫数量会随答错次数累积，但会自动清除
- 背景花朵只在升级到新阶段时添加
- 最大5个生长阶段（可通过修改 `growthStages` 扩展）
