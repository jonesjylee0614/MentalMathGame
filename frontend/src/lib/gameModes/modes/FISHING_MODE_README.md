# 钓鱼模式 (Fishing Mode)

## 📝 概述

钓鱼模式是一个海洋主题的游戏模式，玩家通过答题来钓鱼🎣，收集各种稀有度的鱼类，体验钓鱼的乐趣和惊喜！

## 🎮 游戏玩法

### 核心机制
- **答对题目**：成功钓到一条鱼🐟，加入鱼篓
- **答错题目**：鱼逃跑了💨，错过这条鱼
- **连击系统**：连续答对增加稀有鱼概率和分数加成
- **稀有度系统**：普通→稀有→史诗→传说，越稀有分数越高
- **收集系统**：在鱼篓中查看已钓到的鱼

### 鱼类稀有度

#### 普通鱼 (70%概率)
- 🐟 小鱼 (10分)
- 🐠 热带鱼 (10分)
- 🐡 河豚 (15分)

#### 稀有鱼 (20%概率)
- 🦈 鲨鱼 (30分)
- 🐙 章鱼 (35分)
- 🦑 鱿鱼 (30分)

#### 史诗鱼 (8%概率)
- 🐬 海豚 (50分)
- 🐳 鲸鱼 (60分)

#### 传说鱼 (2%概率)
- 🦀 黄金蟹 (100分)
- 🐉 龙鱼 (150分)

### 连击系统

连击效果：
- **增加稀有鱼概率**：每连击1次，传说鱼概率+0.5%，史诗鱼概率+2%
- **分数加成**：连击数 × 10% × 基础分数
  - 例：连击5次钓到30分的鲨鱼 → 30 + (5 × 0.1 × 30) = 45分

连击中断：
- 答错题目立即清零
- 重新开始累积

## 📋 适用题型

钓鱼模式特别适合：
- ✅ **基础练习题**：5以内、10以内的加减法

### 稀有度计算

```typescript
function generateRandomFish() {
  const random = Math.random() * 100;
  const comboBonus = Math.min(combo * 2, 20); // 连击加成
  
  if (random < 2 + comboBonus * 0.5) {
    // 传说 (2% + 连击加成)
    return legendaryFish;
  } else if (random < 10 + comboBonus) {
    // 史诗 (8% + 连击加成)
    return epicFish;
  } else if (random < 30) {
    // 稀有 (20%)
    return rareFish;
  } else {
    // 普通 (70%)
    return commonFish;
  }
}
```

### 分数计算

```typescript
function calculateScore(fish, combo) {
  const baseScore = fish.score;
  const comboBonus = Math.floor(combo * 0.1 * baseScore);
  return baseScore + comboBonus;
}

// 例子：
// - 连击0次钓到30分鲨鱼 = 30分
// - 连击5次钓到30分鲨鱼 = 30 + 15 = 45分
// - 连击10次钓到100分金蟹 = 100 + 100 = 200分
```

## 🎯 设计亮点

1. **随机性和惊喜感**：不知道会钓到什么鱼，每次都有期待
2. **收集成就感**：鱼篓展示收获，可以看到所有钓到的鱼
3. **连击鼓励机制**：连续答对增加稀有鱼概率，鼓励专注
4. **非惩罚性答错**：答错只是鱼跑了，不扣分，不损失已有收获
5. **视觉丰富**：海洋、波浪、气泡、鱼类、特效应有尽有
6. **儿童友好**：轻松愉快的氛围，适合低年龄段

## 📊 统计系统

### 实时统计
- **总分**：所有钓到的鱼的总分
- **已钓数量**：钓到鱼数/总题目数
- **当前连击**：连续答对次数（火焰🔥标识）
- **最佳连击**：本轮游戏的最高连击数

### 稀有度统计
- 普通鱼：灰色圆点 + 数量
- 稀有鱼：蓝色圆点 + 数量
- 史诗鱼：紫色圆点 + 数量
- 传说鱼：金色圆点 + 数量

### 鱼篓展示
- 显示最近钓到的8条鱼
- 每条鱼显示表情和分数
- 边框颜色对应稀有度
- 可滚动查看更多

## 🎓 教育意义

1. **概率认知**：理解稀有度系统，体验概率概念
2. **激励机制**：连击系统鼓励持续专注
3. **成就收集**：培养收集和整理的习惯
4. **风险意识**：答错会失去当前的鱼，但不影响已有收获
5. **耐心培养**：钓鱼需要耐心，一条一条慢慢钓

## 🎮 游戏策略

### 新手策略
- 稳扎稳打，先熟悉题目
- 不要急于求成，避免答错
- 积累连击后再冲刺高分

### 进阶策略
- 保持连击状态钓传说鱼
- 连击5+时专注度最高
- 利用连击加成最大化分数

### 传说鱼攻略
- 基础概率2%
- 连击10次概率达7%
- 连击15次概率达9.5%
- 需要持续专注和稳定发挥

## 📈 性能优化

### 优化点
- CSS动画GPU加速
- 及时清理定时器
- 鱼篓只展示最近8条（避免DOM过多）
- 使用transform代替position
- 动画完成后移除临时DOM

### 内存管理
```typescript
destroy() {
  // 清理所有定时器
  this.timers.forEach(timer => clearTimeout(timer));
  this.timers = [];
  
  // 清空鱼类数据
  this.state.caughtFish = [];
  this.state.currentFish = null;
}
```

## 🐛 已知限制

- 鱼篓最多显示8条（可滚动查看更多）
- 稀有度是随机的，无法保证一定钓到传说鱼
- 连击最高加成20%（防止分数过高）
