# 防守模式 (Defense Mode)

## 📝 概述

防守模式是一个塔防风格的游戏模式，玩家需要通过快速答题来击退从右侧涌来的敌人，保护左侧的城堡🏰不被攻破。

## 🎮 游戏玩法

### 核心机制
- **敌人入侵**：敌人从右侧（100%）向左侧（0%）移动
- **答对题目**：发射激光💥击退当前敌人
- **答错题目**：给予警告提示，不扣血（但敌人继续前进）
- **敌人到达**：敌人到达城堡造成20点伤害
- **游戏失败**：城堡血量降至0
- **游戏胜利**：击退所有敌人

### 游戏元素

#### 城堡（左侧）
- 初始血量：100 HP
- 受伤效果：抖动 + 红色闪烁
- 危险等级：
  - **安全** (HP > 60%)：绿色光晕
  - **警告** (30% < HP ≤ 60%)：橙色光晕
  - **危险** (HP ≤ 30%)：红色光晕 + 警告标志

#### 防御塔（中间）
- 发射激光攻击敌人
- 答对题目时触发射击

#### 敌人（右侧）
- 多种敌人类型：👾 👹 🦹 🦸 🤖 👽 💀
- 移动速度：每秒0.5%（可调整）
- 每个敌人携带一道题目

## 🎨 视觉效果

### 战场环境
- 深色背景（夜晚战场氛围）
- 路径指示线（敌人移动轨迹）
- 战场雾气效果

### 动画特效


#### 爆炸效果
```css

```

#### 城堡受伤
```css

```

### 状态指示

1. **血量条**：实时显示城堡血量，颜色随危险等级变化
2. **进度条**：显示已击败敌人数量进度
3. **敌人计数**：击败数/总数
4. **危险警告**：血量低于30%时显示"⚠️ 危险！"

## 📋 适用题型

防守模式特别适合：
- ✅ **快速反应题**：需要迅速答题
- ✅ **连除运算**：54÷9÷1
- ✅ **乘除混合**：10÷5×8
- ✅ **除加混合**：48÷6+3
- ✅ **连乘运算**：3×2×7
- ✅ **表内乘除混合**：6以内、9以内

### 核心状态

```typescript
{
  castleHP: 100,              // 城堡当前血量
  maxCastleHP: 100,           // 城堡最大血量
  enemies: [],                // 敌人数组
  currentEnemy: null,         // 当前敌人
  enemiesDefeated: 0,         // 已击败敌人数
  totalEnemies: 0,            // 总敌人数
  waveNumber: 1,              // 当前波次
  showExplosion: false,       // 显示爆炸效果
  showDamage: false,          // 显示受伤效果
  showVictory: false,         // 显示胜利横幅
  lastShot: Date.now()        // 最后一次射击时间
}
```

### 敌人对象

```typescript
interface Enemy {
  id: string;           // 唯一标识
  emoji: string;        // 敌人表情
  position: number;     // 位置（0-100%）
  speed: number;        // 移动速度
  question: Question;   // 携带的题目
  defeated: boolean;    // 是否已被击败
}
```

### 事件系统

模式发射的自定义事件：
- `enemySpawned` - 敌人生成
- `enemyDefeated` - 敌人被击败
- `castleDamaged` - 城堡受伤
- `defenseFailed` - 防守失败
- `defenseComplete` - 防守完成
- `wrongAnswerWarning` - 答错警告

### 生命周期

```typescript
// 游戏开始
onGameStart() {
  - 初始化城堡血量
  - 设置总敌人数
}

// 答对题目
onCorrectAnswer() {
  - 找到当前敌人
  - 标记为已击败
  - 播放激光和爆炸动画
  - 1秒后移除敌人
  - 检查是否全部完成
}

// 答错题目
onWrongAnswer() {
  - 显示警告提示
  - 敌人继续前进（不惩罚）
}

// 每秒更新
onUpdate() {
  - 更新所有敌人位置
  - 检查是否到达城堡
  - 触发状态更新
}

// 敌人到达城堡
onEnemyReachCastle() {
  - 城堡扣血20点
  - 播放受伤效果
  - 移除敌人
  - 检查是否失败
}
```

## 🎯 设计亮点

1. **时间压力感**：敌人持续前进，需要快速答题
2. **视觉冲击力**：激光、爆炸、受伤等多种特效
3. **紧张氛围**：夜晚战场、危险警告、血量低时的红色效果
4. **成就感强**：击退敌人有明确的视觉反馈
5. **非惩罚性答错**：答错不扣血，只是敌人继续前进，给玩家改正机会
6. **进度可视化**：血量条、进度条、敌人计数清晰展示

## 📊 难度调整

可通过配置调整难度：

```typescript
modeConfig: {
  enemySpeed: 0.8,      // 敌人速度（默认0.5）
  damage: 30,           // 每个敌人伤害（默认20）
  castleHP: 80,         // 城堡初始血量（默认100）
  enemyTypes: ['👾', '💀']  // 自定义敌人类型
}
```

## 🎓 教育意义

1. **时间管理**：培养在压力下快速思考的能力
2. **专注力**：需要持续关注敌人位置和答题
3. **风险评估**：判断何时可以稍慢一些，何时必须快速
4. **坚持不懈**：即使血量低也不放弃

## 📈 性能优化

### 优化点
- 使用CSS动画（GPU加速）
- 及时清理定时器和interval
- 合理控制敌人数量（逐个生成，不是一次全部）
- 使用CSS transform代替position改变位置
- 爆炸动画结束后及时移除DOM元素

### 内存管理
```typescript
destroy() {
  // 清理所有定时器
  this.timers.forEach(timer => clearTimeout(timer));
  
  // 清理所有interval
  this.intervals.forEach(interval => clearInterval(interval));
  
  // 清空敌人数组
  this.state.enemies = [];
}
```

## 🐛 已知限制

- 敌人当前是匀速移动，未来可以添加加速机制
- 暂不支持多波次（所有敌人在同一波）
- 城堡没有反击能力（只依靠玩家答题）
- 最大敌人数受题目数量限制

## 🔜 未来改进

可能的扩展方向：
- **多波次系统**：每5题一波，波次间有休息时间
- **敌人分级**：小兵、精英、BOSS，不同血量和伤害
- **城堡技能**：连续答对触发特殊技能（AOE攻击、时间减速等）
- **地形元素**：陷阱、减速带、障碍物
- **天气系统**：白天/夜晚、晴天/雨天影响视觉
- **升级系统**：答题赚取金币升级防御塔

## 🎬 游戏流程示例

```
1. 游戏开始 → 城堡血量100
2. 第一个敌人👾从右侧出现 → 携带题目 "6×7=?"
3. 玩家答对 "42" → 激光发射💥 → 敌人爆炸消失
4. 第二个敌人👹出现 → 携带题目 "48÷6=?"
5. 玩家答错 "9" → 警告提示 → 敌人继续前进
6. 玩家重新答对 "8" → 激光发射 → 敌人爆炸
7. 第三个敌人🤖出现，但玩家太慢...
8. 敌人到达城堡 → 城堡-20 HP → 血量降至80
9. ...继续战斗...
10. 所有敌人击退 → 显示"🏆 防守成功！城堡安全！"
```
