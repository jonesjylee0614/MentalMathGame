# 关卡题目数量分析

## 问题关卡分析

### 1. 5以内运算（max=5）
**可能组合数计算：**

#### 加法 (add_1_5)
- 0+0到5+5的所有组合
- 去掉和>5的：(6×6 - 15) = 21种
- **配置：20题** ✅ 勉强够用

#### 减法 (sub_1_5)  
- 0-0到5-5，结果≥0的组合
- 只有：1+2+3+4+5+6 = 21种
- **配置：20题** ⚠️ **太紧张，建议10题**

#### 加减混合 (addsub_1_5)
- 加法21种 + 减法21种 = 42种
- **配置：20题** ✅ 够用

### 2. 10以内运算（max=10）

#### 加法 (add_1_10)
- 0+0到10+10，和≤10
- 约 (11×11 - 55) = 66种
- **配置：25题** ✅ 够用

#### 减法 (sub_1_10)
- 0-0到10-10，结果≥0
- 约 1+2+...+11 = 66种
- **配置：25题** ✅ 够用

#### 加减混合 (addsub_1_10)
- 加法66种 + 减法66种 = 132种
- **配置：25题** ✅ 够用

#### 填括号 (fill_1_10)
- 10以内的填空题
- 约 60-80种变化
- **配置：20题** ✅ 够用
