# 登录调试指南

## 问题描述
用户在登录页面点击登录按钮后，调用了login接口，但又返回到登录页面，无法正常跳转到首页。

### 2. 前端持久化日志系统

#### 实现文件
`frontend/src/lib/persistentLogger.ts`

#### 特性
- **持久化存储**：日志保存在 localStorage，页面刷新不丢失
- **多级别**：支持 debug、info、warn、error 四个级别
- **容量限制**：最多保存 500 条日志
- **同步输出**：同时输出到浏览器控制台
- **导出功能**：可导出为文本文件

#### 使用方式
```typescript
import { persistentLogger } from '../lib/persistentLogger';

// 记录日志
persistentLogger.info('用户登录', { username: 'test' });
persistentLogger.error('登录失败', { error: err });

// 查看日志
const logs = persistentLogger.getLogs();

// 清空日志
persistentLogger.clearLogs();
```

### 常见问题排查

#### 问题1：后端返回401或400错误
**查看后端日志**：
- 用户不存在？→ `[WARN] 用户不存在`
- 密码错误？→ `[WARN] 密码验证失败`
- 账号禁用？→ `[WARN] 账号已被禁用`

#### 问题2：前端收到响应但无法跳转
**查看前端日志**：
- Token是否保存成功？→ 查找 `保存token到localStorage`
- 用户状态是否更新？→ 查找 `设置用户信息到状态`
- navigate是否调用？→ 查找 `navigate函数已调用`

#### 问题3：响应格式错误
**查看前端日志**：
```
[ERROR] 登录响应格式错误：缺少token { response: {...} }
```
说明后端返回的数据结构不正确。

#### 问题4：网络错误
**查看前端日志**：
```
[ERROR] 登录失败 { error: "Network Error", errorType: "AxiosError" }
```
检查：
- 后端是否正常运行？
- CORS配置是否正确？
- API地址是否正确？

## 修复的已知问题

### 1. nil指针问题
**位置**：`backend/internal/service/auth_service.go:172`

**问题**：`LastLoginAt`字段是`*time.Time`类型，可能为nil，直接调用`.Format()`会panic。

**修复**：
```go
lastLoginAt := ""
if user.LastLoginAt != nil {
    lastLoginAt = user.LastLoginAt.Format(time.RFC3339)
}
```

### 2. 响应数据验证
**位置**：`frontend/src/context/AuthContext.tsx`

**新增**：响应数据完整性检查
```typescript
if (!response.data || !response.data.token) {
    persistentLogger.error('登录响应格式错误：缺少token', { response });
    throw new Error('登录响应格式错误');
}
```
