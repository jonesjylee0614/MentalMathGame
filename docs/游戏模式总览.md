## 📖 模式详细说明

### 1. 战斗模式 (Battle Mode) ⚔️

**核心玩法**：
- 植物 🌻 vs 僵尸 🧟 的经典对战
- 答对：植物发射子弹攻击僵尸
- 答错：僵尸扔石头攻击植物
- 通过血条显示战斗进度

**视觉特效**：
- 子弹飞行动画
- 受伤闪烁效果
- 攻击动作动画
- 鼓励消息提示

**适用场景**：
- 基础加减法练习
- 乘除法口诀
- 需要激励的中等难度题目

**配置选项**：
```typescript
{
  theme: 'plants' | 'warriors' | 'robots',  // 战斗主题
  difficulty: 'easy' | 'medium' | 'hard'     // 难度等级
}
```

---

### 2. 建造模式 (Building Mode) 🏗️

**核心玩法**：
- 搭建高塔、城堡或桥梁
- 答对：添加一块积木，建筑逐渐长高
- 答错：积木晃动，不添加
- 完成后展示完整建筑

**视觉特效**：
- 积木飞入动画
- 堆叠效果
- 进度条显示
- 完成时的烟花效果

**适用场景**：
- 连加题目（累积效果明显）
- 整数运算
- 需要成就感的长题目

**配置选项**：
```typescript
{
  buildingType: 'tower' | 'castle' | 'bridge',  // 建筑类型
  blockStyle: 'brick' | 'stone' | 'wood'         // 积木风格
}
```

---

### 3. 收集模式 (Collection Mode) 🎁

**核心玩法**：
- 收集水果、宝石或海洋生物
- 答对：物品飞入篮子
- 答错：物品从篮子掉出
- 填满篮子获胜

**视觉特效**：
- 贝塞尔曲线飞行路径
- 物品掉落动画
- 篮子填充效果
- 收集音效

**适用场景**：
- 填空题（匹配收集感）
- 单位换算（分类整理）
- 比较大小

**配置选项**：
```typescript
{
  theme: 'fruit' | 'gem' | 'ocean',   // 收集主题
  containerType: 'basket' | 'cart' | 'bucket'  // 容器类型
}
```

---

### 4. 赛跑模式 (Racing Mode) 🏃

**核心玩法**：
- 与对手（乌龟、兔子、机器人）竞速
- 答对：我方前进一大步
- 答错：对手前进
- 先到终点者获胜

**视觉特效**：
- 角色移动动画
- 速度线条效果
- 冲刺动画
- 胜利/失败特效

**适用场景**：
- 加减混合（需要快速计算）
- 连减题目
- 比较题

**配置选项**：
```typescript
{
  character: 'runner' | 'car' | 'swimmer',  // 角色类型
  opponent: 'turtle' | 'rabbit' | 'robot',   // 对手类型
  trackLength: number  // 赛道长度
}
```

---

### 5. 解密模式 (Puzzle Mode) 🧩

**核心玩法**：
- 逐渐揭示图片、解锁密码或开启宝箱
- 答对：揭示一部分内容
- 答错：无变化（不倒退）
- 完全揭示后成功

**视觉特效**：
- 模糊到清晰效果
- 拼图块出现动画
- 解锁层级效果
- 宝箱开启动画

**适用场景**：
- 含括号的复杂运算
- 三数加减混合
- 挑战性题目

**配置选项**：
```typescript
{
  puzzleType: 'image' | 'lock' | 'chest',  // 解谜类型
  difficulty: 'easy' | 'medium' | 'hard'    // 难度
}
```

---

### 6. 种植模式 (Farming Mode) 🌱

**核心玩法**：
- 种植并培育植物成长
- 答对：植物生长一个阶段
- 答错：害虫出现，需额外答题驱赶
- 植物完全开花获胜

**视觉特效**：
- 生长阶段动画（种子→发芽→开花）
- 害虫出现动画
- 浇水、施肥效果
- 花园全景

**适用场景**：
- 乘法口诀（需要反复练习）
- 表内除法
- 长时间关卡（30+题）

**配置选项**：
```typescript
{
  plantType: 'flower' | 'tree' | 'crop',  // 植物类型
  stages: number  // 生长阶段数
}
```

---

### 7. 探险模式 (Adventure Mode) 🗺️

**核心玩法**：
- 在地图上探索，从起点到终点
- 每个节点是一道题
- 答对：前进到下一个节点
- 答错：停留原地，出现路障
- 特殊节点：宝箱（奖励）、陷阱（困难题）

**视觉特效**：
- 地图路径动画
- 角色移动效果
- 节点解锁动画
- Boss战特效

**适用场景**：
- 整千数/整百数运算
- 混合运算
- 综合题型

**配置选项**：
```typescript
{
  mapTheme: 'forest' | 'desert' | 'mountain',  // 地图主题
  nodeCount: number  // 节点数量
}
```

---

### 8. 防守模式 (Defense Mode) 🛡️

**核心玩法**：
- 敌人从右侧源源不断走来
- 每个敌人携带一道题
- 答对：击退敌人
- 答错/超时：敌人到达城堡，城堡扣血
- 城堡被攻破则失败

**视觉特效**：
- 敌人行进动画
- 攻击特效
- 城堡受损效果
- 波次计数

**适用场景**：
- 连除题目
- 除加混合
- 快速反应类题目

**配置选项**：
```typescript
{
  enemyType: 'zombie' | 'alien' | 'monster',  // 敌人类型
  waveCount: number  // 波次数量
}
```

---

### 9. 钓鱼模式 (Fishing Mode) 🎣

**核心玩法**：
- 在池塘边钓鱼
- 答对：钓上一条鱼，放入鱼篓
- 答错：鱼逃跑
- 钓够指定数量的鱼获胜

**视觉特效**：
- 抛竿动画
- 鱼咬钩动画
- 鱼上钩拉起效果
- 水波纹效果

**适用场景**：
- 基础加减法
- 10以内运算
- 轻松简单的题目

**配置选项**：
```typescript
{
  pond: 'lake' | 'river' | 'ocean',  // 钓鱼地点
  fishTypes: string[]  // 鱼的种类
}
```

---

### 10. 烹饪模式 (Cooking Mode) 🍳

**核心玩法**：
- 制作料理，完成菜谱
- 答对：添加一个食材
- 答错：食材掉落
- 完成菜品获胜

**视觉特效**：
- 食材飞入锅中
- 烹饪过程动画
- 火焰效果
- 完成时的菜品展示

**适用场景**：
- 进位加法
- 退位减法
- 中等难度题目

**配置选项**：
```typescript
{
  dish: 'soup' | 'cake' | 'pizza',  // 菜品类型
  difficulty: 'easy' | 'medium' | 'hard'  // 烹饪难度
}
```

---

### 11. 音乐模式 (Music Mode) 🎵

**核心玩法**：
- 演奏音乐，完成旋律
- 答对：播放音符，旋律前进
- 答错：不和谐音
- 完成完整曲目获胜

**视觉特效**：
- 音符飞行动画
- 节奏可视化
- 乐器演奏效果
- 完成时的音乐播放

**适用场景**：
- 节奏性题目
- 20以内加减法
- 需要韵律感的练习

**配置选项**：
```typescript
{
  melody: 'happy' | 'calm' | 'exciting',  // 旋律风格
  instrument: 'piano' | 'guitar' | 'drums'  // 乐器类型
}
```

## 🎯 模式选择指南

### 按题型推荐

| 题型 | 首选模式 | 备选模式 |
|-----|---------|---------|
| 5-10以内加减 | 🎣 钓鱼 | 🏗️ 建造、🎁 收集 |
| 20以内加减 | 🏗️ 建造 | 🎣 钓鱼、🏃 赛跑 |
| 填空题 | 🧩 解密 | 🎁 收集 |
| 凑10练习 | 🎣 钓鱼 | 🎁 收集 |
| 进位加法 | 🍳 烹饪 | ⚔️ 战斗 |
| 退位减法 | 🍳 烹饪 | ⚔️ 战斗 |
| 三数连加/减 | 🏃 赛跑 | 🏗️ 建造 |
| 乘法口诀 | 🌱 种植 | 🛡️ 防守、⚔️ 战斗 |
| 除法 | 🛡️ 防守 | 🌱 种植 |
| 乘除混合 | 🛡️ 防守 | ⚔️ 战斗 |
| 单位换算 | 🎁 收集 | 🧩 解密 |
| 比较大小 | 🏃 赛跑 | 🎁 收集 |
| 大数运算 | 🗺️ 探险 | 🏗️ 建造 |
| 括号混合 | 🧩 解密 | 🗺️ 探险 |

### 按难度推荐

| 难度范围 | 推荐模式 |
|---------|---------|
| 1.0-1.2 (简单) | 🎣 钓鱼、🎁 收集、🏗️ 建造 |
| 1.2-1.5 (入门) | 🏗️ 建造、🏃 赛跑、🎵 音乐 |
| 1.5-2.0 (中等) | ⚔️ 战斗、🍳 烹饪、🛡️ 防守 |
| 2.0-2.5 (困难) | 🛡️ 防守、🧩 解密、🌱 种植 |
| 2.5+ (挑战) | 🧩 解密、🗺️ 探险 |

### 按年龄段推荐

| 年龄段 | 推荐模式 | 理由 |
|-------|---------|------|
| 5-6岁 | 🎣 钓鱼、🎁 收集、🏗️ 建造 | 可爱、直观、无压力 |
| 7-8岁 | 🏗️ 建造、🏃 赛跑、🍳 烹饪 | 适度挑战、有趣味 |
| 9-10岁 | ⚔️ 战斗、🛡️ 防守、🌱 种植 | 策略性、成就感强 |
| 11+岁 | 🧩 解密、🗺️ 探险、⚔️ 战斗 | 挑战性、深度 |

## 🤝 贡献指南

### 如何添加新模式

1. **设计阶段**
   - 定义模式核心玩法
   - 设计视觉效果
   - 确定适用题型

2. **实现阶段**
   - 创建模式类（继承 BaseGameMode）
   - 实现 React 组件
   - 编写 CSS 动画

3. **测试阶段**
   - 单元测试
   - 集成测试
   - 用户测试

4. **文档阶段**
   - 更新本文档
   - 编写模式说明
   - 提供配置示例

详细步骤请参考：[模式开发指南](../frontend/src/lib/gameModes/modes/README.md)
