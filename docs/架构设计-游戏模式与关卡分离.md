# 游戏模式与关卡分离架构设计

## 📋 背景

### 当前问题
- **耦合过紧**：每个关卡固定绑定一个游戏模式
- **灵活性不足**：用户无法选择用不同模式玩同一个关卡
- **例如**："5以内的加法" 只能用建造模式玩，无法切换到收集、战斗等其他模式

### 改进目标
1. **解耦设计**：关卡内容（题型、难度）与游戏模式（视觉表现）完全分离
2. **自由选择**：用户可以选择任意模式来玩任意关卡
3. **推荐模式**：每个关卡提供推荐的游戏模式，但不强制
4. **兼容性**：保持现有代码结构，最小化改动

---

## 🎯 核心设计思想

### 概念分离

```
关卡内容 (Level Content)
├── 题型 (问题生成器)
├── 难度
├── 题目数量
├── 时间限制
└── 分类标签

游戏模式 (Game Mode)
├── 视觉表现
├── 动画效果
├── 交互方式
└── 反馈机制
```

**关键原则**：
- 关卡定义 **"玩什么"** (题型、难度)
- 游戏模式定义 **"怎么玩"** (视觉、动画)
- 两者通过标准接口通信，完全解耦

### 3. 模式选择器组件

```tsx
// frontend/src/components/ModeSelector.tsx

import React from 'react';
import { GameMode, Level } from '../lib/types';
import { MODE_COMPATIBILITY } from '../lib/gameModes/compatibility';
import styles from '../styles/ModeSelector.module.css';

interface ModeSelectorProps {
  level: Level;
  selectedMode: GameMode | null;
  onSelectMode: (mode: GameMode) => void;
}

export const ModeSelector: React.FC<ModeSelectorProps> = ({
  level,
  selectedMode,
  onSelectMode
}) => {
  // 获取推荐模式
  const recommendedModes = level.recommendedModes || [level.defaultMode || 'battle'];
  
  // 获取所有可用模式
  const allModes = MODE_COMPATIBILITY.map(m => m.modeId);
  
  return (
    <div className={styles.container}>
      <h3>选择游戏模式</h3>
      
      {/* 推荐模式 */}
      <div className={styles.recommended}>
        <label>推荐模式：</label>
        <div className={styles.modeGrid}>
          {recommendedModes.map(mode => {
            const modeInfo = MODE_COMPATIBILITY.find(m => m.modeId === mode);
            return (
              <button
                key={mode}
                className={`${styles.modeCard} ${selectedMode === mode ? styles.selected : ''}`}
                onClick={() => onSelectMode(mode)}
              >
                <div className={styles.modeIcon}>{getModeIcon(mode)}</div>
                <div className={styles.modeName}>{modeInfo?.name}</div>
                <div className={styles.modeDesc}>{modeInfo?.description}</div>
              </button>
            );
          })}
        </div>
      </div>
      
      {/* 所有模式 */}
      <details className={styles.allModes}>
        <summary>查看所有模式</summary>
        <div className={styles.modeGrid}>
          {allModes.map(mode => {
            if (recommendedModes.includes(mode)) return null; // 已在推荐中显示
            const modeInfo = MODE_COMPATIBILITY.find(m => m.modeId === mode);
            return (
              <button
                key={mode}
                className={`${styles.modeCard} ${selectedMode === mode ? styles.selected : ''}`}
                onClick={() => onSelectMode(mode)}
              >
                <div className={styles.modeIcon}>{getModeIcon(mode)}</div>
                <div className={styles.modeName}>{modeInfo?.name}</div>
              </button>
            );
          })}
        </div>
      </details>
    </div>
  );
};

function getModeIcon(mode: GameMode): string {
  const icons: Record<GameMode, string> = {
    battle: '⚔️',
    building: '🏗️',
    collection: '🎁',
    racing: '🏃',
    puzzle: '🧩',
    farming: '🌱',
    adventure: '🗺️',
    defense: '🛡️',
    fishing: '🎣',
    cooking: '🍳'
  };
  return icons[mode] || '🎮';
}
```

## 🔄 迁移方案

### 阶段1：保持兼容（即时可用）
1. 保留 Level 中的 `gameMode` 字段（向后兼容）
2. 如果 `gameMode` 存在，则作为 `defaultMode`
3. 如果 `gameMode` 不存在，则使用 `defaultMode`，都不存在则使用 `'battle'`

```typescript
// 兼容性处理函数
export function getDefaultMode(level: Level): GameMode {
  // 优先使用新字段
  if (level.defaultMode) return level.defaultMode;
  
  // 回退到旧字段
  if (level.gameMode) return level.gameMode;
  
  // 最终默认值
  return 'battle';
}

export function getRecommendedModes(level: Level): GameMode[] {
  if (level.recommendedModes && level.recommendedModes.length > 0) {
    return level.recommendedModes;
  }
  
  // 如果没有推荐模式，则根据题型自动推荐
  return autoRecommendModes(level);
}

function autoRecommendModes(level: Level): GameMode[] {
  const generatorType = (level.generator as any).type;
  
  // 根据题型自动推荐
  const recommendations: Record<string, GameMode[]> = {
    'addsub': ['building', 'fishing', 'racing', 'battle'],
    'fill': ['puzzle', 'collection', 'fishing'],
    'mulTable': ['farming', 'defense', 'battle'],
    'divTable': ['defense', 'farming', 'battle'],
    'chain': ['racing', 'adventure', 'puzzle'],
    'unitConv': ['collection', 'puzzle'],
    'compare': ['racing', 'collection'],
    'parenMix': ['puzzle', 'adventure']
  };
  
  return recommendations[generatorType] || ['battle', 'building', 'racing'];
}
```

## 🎮 用户体验流程

### 流程1：首次玩关卡
1. 用户在关卡列表点击某个关卡
2. 侧边栏弹出，显示：
   - 关卡信息
   - 推荐的游戏模式（3-4个）

1. 用户再次点击同一关卡
2. 侧边栏显示上次选择的模式（已高亮）
3. 用户可以：
   - 继续使用上次的模式
   - 切换到其他推荐模式
   - 查看所有模式

### 流程3：快速开始
1. 用户在关卡卡片上双击
2. 直接使用默认模式（或上次选择的模式）开始游戏
3. 游戏中可以通过菜单切换模式（可选功能）

## 💡 智能推荐算法（可选增强）

```typescript
// frontend/src/lib/gameModes/recommendation.ts

/**
 * 根据用户历史和关卡特性，智能推荐游戏模式
 */
export function smartRecommendModes(
  level: Level,
  userHistory?: {
    preferredModes: Record<GameMode, number>; // 各模式的使用次数
    levelProgress: Record<string, ProgressEntry>; // 关卡进度
  }
): GameMode[] {
  // 1. 获取基础推荐
  const baseRecommendations = level.recommendedModes || autoRecommendModes(level);
  
  // 如果没有用户历史，直接返回基础推荐
  if (!userHistory) return baseRecommendations;
  
  // 2. 根据用户偏好调整顺序
  const userPreferred = Object.entries(userHistory.preferredModes)
    .sort((a, b) => b[1] - a[1])
    .map(([mode]) => mode as GameMode)
    .filter(mode => baseRecommendations.includes(mode));
  
  // 3. 根据关卡失败次数推荐简单模式
  const levelProgress = userHistory.levelProgress[level.id];
  if (levelProgress && levelProgress.playCount > 3) {
    const failRate = 1 - (levelProgress.bestAccuracy / 100);
    if (failRate > 0.5) {
      // 失败率高，推荐轻松模式
      return ['fishing', 'collection', ...baseRecommendations];
    }
  }
  
  // 4. 合并推荐：用户偏好 + 基础推荐
  return [...new Set([...userPreferred, ...baseRecommendations])];
}
```

## 📚 总结

### 核心改变
| 维度 | 旧设计 | 新设计 |
|-----|-------|-------|
| 关卡定义 | 固定绑定一个模式 | 推荐多个模式，用户可选 |
| 用户选择 | 无选择权 | 完全自由选择 |
| 扩展性 | 新增模式需修改关卡 | 新增模式自动适配 |
| 灵活性 | 低 | 高 |

### 关键优势
1. **解耦设计**：关卡和模式完全独立
2. **用户自由**：想怎么玩就怎么玩
