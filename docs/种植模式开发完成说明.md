## 🌱 种植模式详解

### 核心概念

**主题**: 照顾花园，看植物从种子长成花朵

**适用题型**:
- ✅ 乘法口诀（需要重复练习）
- ✅ 表内除法（长时间关卡）
- ✅ 任何30+题的关卡

**成长机制**:
- 每株植物有5个成长阶段
- 根据答对数量自动推进生长
- 多株植物依次成长（第一株完成后激活第二株）

### 生长阶段

```typescript
🌱 种子   (Stage 0) - 刚种下
🌿 发芽   (Stage 1) - 开始生长
🪴 幼苗   (Stage 2) - 茁壮成长
🌻 开花   (Stage 3) - 即将盛开
🌺 盛开   (Stage 4) - 完全成熟
```

### 技术特点

#### 1. 智能植物布局算法
```typescript
// 自动计算植物数量（3-8株）
plantsCount = Math.max(3, Math.min(8, Math.ceil(totalQuestions / 5)));

// 网格布局算法
const rows = Math.ceil(Math.sqrt(total));
const cols = Math.ceil(total / rows);

// 带随机偏移的位置计算
const baseX = (col + 0.5) / cols * 100;
const baseY = (row + 0.5) / rows * 100;
const randomOffset = (Math.random() - 0.5) * 5;
```

#### 2. 渐进式生长逻辑
```typescript
// 每株植物需要的题目数
const questionsPerPlant = Math.ceil(totalQuestions / plantsCount);

// 当前激活的植物
const currentPlantIndex = Math.floor((correctCount - 1) / questionsPerPlant);

// 植物内的生长阶段
const stageWithinPlant = Math.floor(
  ((correctCount - 1) % questionsPerPlant) / questionsPerPlant * GROWTH_STAGES.length
);
```

## 📊 使用配置

### 基础配置
```typescript
{
  id: 'your_level',
  name: '你的关卡',
  generator: { type: 'mulTable', maxTable: 9 },
  count: 30,  // 建议 20-40 题
  timeSec: 140,
  difficulty: 1.8,

  modeConfig: {
    gardenType: 'flower',  // 可选: 'flower' | 'tree' | 'vegetable'

  }
}
```

### 花园类型

1. **flower** (默认) - 花园主题
   - 背景：天蓝→米黄→翠绿
   - 适合：乘法口诀、除法

2. **tree** - 树林主题
   - 背景：天蓝→青绿→深绿
   - 适合：大数运算、复杂题型

3. **vegetable** - 菜园主题
   - 背景：天蓝→浅黄→棕土
   - 适合：单位换算、应用题
