# 游戏模式随机化功能实现

**日期**: 2025-11-08  
**功能**: 每次进入关卡时随机选择游戏模式

## 📋 需求背景

用户希望每次进入关卡时，游戏模式（动画）是随机的，而不是固定的。这样可以：
- 增加游戏的趣味性和新鲜感
- 让孩子在重复练习时不会感到枯燥
- 同一关卡可以体验不同的游戏玩法

## ✅ 实现功能

### 1. 随机模式选择机制

#### 核心逻辑
```typescript
// 从推荐模式列表中随机选择一个
if (level.recommendedModes && level.recommendedModes.length > 0) {
  const randomIndex = Math.floor(Math.random() * level.recommendedModes.length);
  modeId = level.recommendedModes[randomIndex];
} else {
  // 如果没有推荐模式，使用默认模式或battle
  modeId = level.gameMode || level.defaultMode || 'battle';
}
```

#### 特点
- ✅ 每次进入关卡都重新随机选择
- ✅ 从关卡配置的 `recommendedModes` 列表中选择
- ✅ 如果没有推荐模式，则使用默认模式
- ✅ 完全随机，每次都可能不同

### 2. 当前模式显示

#### 界面展示
- ✅ 游戏页面顶部显示当前使用的游戏模式
- ✅ 显示格式：图标 + 模式名称（如：⚔️ 战斗模式）
- ✅ 蓝色徽章样式，与关卡序号区分

#### 用户体验
- 用户可以清楚地知道当前是什么游戏模式
- 重复练习时可以体验不同的游戏玩法
- 增加了游戏的可玩性和趣味性

## 🎯 技术实现细节

### 随机选择时机
- 在 `useEffect` 中，每次组件挂载时执行
- 由于 `useEffect` 依赖于 `level`，每次进入关卡都会重新执行
- 使用 `Math.random()` 确保真正的随机性

### 状态管理
```typescript
const [currentModeId, setCurrentModeId] = useState<string>('');

// 在创建游戏模式时保存
setCurrentModeId(modeId);

// 在界面上使用
{currentModeId && (
  <span className={styles.gameModeBadge}>
    {getGameModeIcon(currentModeId)} {getGameModeName(currentModeId)}模式
  </span>
)}
```

### 向后兼容
- 如果关卡没有配置 `recommendedModes`，则使用 `gameMode` 或 `defaultMode`
- 确保旧关卡配置仍然可以正常工作
- 不会破坏现有功能
