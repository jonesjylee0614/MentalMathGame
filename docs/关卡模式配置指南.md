# 关卡与游戏模式配置指南

## 📋 概述

本文档说明如何为关卡配置游戏模式，包括推荐模式、默认模式和模式专用配置。

---

## 🎯 核心概念

### 关卡配置的三个关键字段

```typescript
interface Level {
  // ... 其他字段 ...
  
  recommendedModes?: GameMode[];    // 推荐的游戏模式列表
  defaultMode?: GameMode;           // 默认模式
  modeConfig?: Record<string, any>; // 模式专用配置
  
  // 向后兼容
  gameMode?: GameMode; // @deprecated 使用 defaultMode 代替
}
```

### 工作原理

1. **推荐模式列表** (`recommendedModes`)
   - 显示在关卡选择界面
   - 用户可以从中选择喜欢的模式
   - 通常推荐3-4个模式
   - 如果未配置，系统会根据题型自动推荐

2. **默认模式** (`defaultMode`)
   - 用户未选择时使用的模式
   - 通常是推荐模式列表中的第一个
   - 如果未配置，回退到 `gameMode` 字段
   - 都未配置则使用 `'battle'`

3. **模式专用配置** (`modeConfig`)
   - 为不同模式提供不同的配置参数
   - 支持两种格式：
     - 新格式（推荐）：`{ building: {...}, collection: {...} }`
     - 旧格式（兼容）：`{ buildingType: 'tower' }`

## ✨ 配置示例

### 示例1：基础配置

```typescript
{
  id: 'add_1_5',
  name: '5以内的加法',
  // ... 其他字段 ...
  
  // 推荐3个模式
  recommendedModes: ['building', 'fishing', 'collection'],
  
  // 默认使用建造模式
  defaultMode: 'building'
}
```

**说明**：
- 用户可以选择建造、钓鱼或收集模式
- 如果用户不选择，默认使用建造模式
- 所有模式使用默认配置

### 示例2：带模式专用配置

```typescript
{
  id: 'add_1_5',
  name: '5以内的加法',
  // ... 其他字段 ...
  
  recommendedModes: ['building', 'fishing', 'collection'],
  defaultMode: 'building',
  
  // 为不同模式提供专用配置
  modeConfig: {
    building: {
      buildingType: 'tower'  // 建造模式专用：建造塔
    },
    collection: {
      theme: 'fruit'         // 收集模式专用：收集水果
    }
    // fishing 没有专用配置，使用默认配置
  }
}
```

**说明**：
- 建造模式会建造塔（而不是城堡或桥）
- 收集模式会收集水果（而不是宝石或海洋生物）
- 钓鱼模式使用默认配置

### 示例3：自动推荐模式

```typescript
{
  id: 'mul_6',
  name: '6以内的乘法口诀',
  generator: { type: 'mulTable', maxTable: 6 },
  // ... 其他字段 ...
  
  // 不配置 recommendedModes，系统会自动推荐
  defaultMode: 'farming'
}
```

**说明**：
- 系统会根据题型 `mulTable` 自动推荐适合的模式
- 自动推荐算法会考虑：题型、分类、难度
- 预计推荐：`['farming', 'defense', 'battle']`

## 📊 模式推荐规则

### 按题型推荐

| 题型 | 自动推荐的模式 |
|-----|---------------|
| `addsub` | building, fishing, racing, battle |
| `fill` | puzzle, collection, fishing |
| `mulTable` | farming, defense, battle |
| `divTable` | defense, farming, battle |
| `chain` | racing, adventure, puzzle |
| `unitConv` | collection, puzzle |
| `compare` | racing, collection |
| `parenMix` | puzzle, adventure |
| `carryAdd` / `borrowSub` | cooking, battle |

### 按难度推荐

| 难度范围 | 推荐的模式风格 |
|---------|--------------|
| 1.0-1.2 (简单) | fishing, collection, building |
| 1.2-1.5 (入门) | building, racing, music |
| 1.5-2.0 (中等) | battle, cooking, defense |
| 2.0-2.5 (困难) | defense, puzzle, farming |
| 2.5+ (挑战) | puzzle, adventure |

## 🔧 模式配置参数

### 建造模式 (building)

```typescript
modeConfig: {
  building: {
    buildingType: 'tower' | 'castle' | 'bridge',  // 建筑类型
    blockStyle?: 'brick' | 'stone' | 'wood'        // 积木风格
  }
}
```

### 收集模式 (collection)

```typescript
modeConfig: {
  collection: {
    theme: 'fruit' | 'gem' | 'ocean',      // 收集主题
    containerType?: 'basket' | 'cart' | 'bucket'  // 容器类型
  }
}
```

### 解密模式 (puzzle)

```typescript
modeConfig: {
  puzzle: {
    puzzleType: 'image' | 'lock' | 'chest',  // 解谜类型
    difficulty?: 'easy' | 'medium' | 'hard'   // 难度
  }
}
```

### 赛跑模式 (racing)

```typescript
modeConfig: {
  racing: {
    character?: 'runner' | 'car' | 'swimmer',  // 角色类型
    opponent?: 'turtle' | 'rabbit' | 'robot',   // 对手类型
    trackLength?: number  // 赛道长度
  }
}
```

### 种植模式 (farming)

```typescript
modeConfig: {
  farming: {
    plantType?: 'flower' | 'tree' | 'crop',  // 植物类型
    stages?: number  // 生长阶段数
  }
}
```

### 防守模式 (defense)

```typescript
modeConfig: {
  defense: {
    enemyType?: 'zombie' | 'alien' | 'monster',  // 敌人类型
    waveCount?: number  // 波次数量
  }
}
```

### 烹饪模式 (cooking)

```typescript
modeConfig: {
  cooking: {
    dish?: 'soup' | 'cake' | 'pizza',  // 菜品类型
    difficulty?: 'easy' | 'medium' | 'hard'  // 烹饪难度
  }
}
```

### 音乐模式 (music)

```typescript
modeConfig: {
  music: {
    melody?: 'happy' | 'calm' | 'exciting',  // 旋律风格
    instrument?: 'piano' | 'guitar' | 'drums'  // 乐器类型
  }
}
```

### 钓鱼模式 (fishing)

```typescript
modeConfig: {
  fishing: {
    pond?: 'lake' | 'river' | 'ocean',  // 钓鱼地点
    fishTypes?: string[]  // 鱼的种类
  }
}
```

### 战斗模式 (battle)

```typescript
modeConfig: {
  battle: {
    theme?: 'plants' | 'warriors' | 'robots',  // 战斗主题
    difficulty?: 'easy' | 'medium' | 'hard'     // 难度等级
  }
}
```

### 探险模式 (adventure)

```typescript
modeConfig: {
  adventure: {
    mapTheme?: 'forest' | 'desert' | 'mountain',  // 地图主题
    nodeCount?: number  // 节点数量
  }
}
```

## 🎯 配置最佳实践

### 1. 推荐模式数量

**建议**：每个关卡推荐 3-4 个模式

```typescript
// ✅ 好：3-4个推荐模式
recommendedModes: ['building', 'fishing', 'collection']

// ⚠️ 可以：2个推荐模式（有点少）
recommendedModes: ['battle', 'racing']

// ❌ 不好：只有1个推荐模式（失去选择意义）
recommendedModes: ['building']

// ❌ 不好：太多推荐模式（选择困难）
recommendedModes: ['building', 'fishing', 'collection', 'racing', 'battle', 'puzzle']
```

### 2. 默认模式选择

**建议**：默认模式应该是推荐模式列表中的第一个

```typescript
// ✅ 好：默认模式在推荐列表中
recommendedModes: ['fishing', 'collection', 'building']
defaultMode: 'fishing'

// ⚠️ 不推荐：默认模式不在推荐列表中
recommendedModes: ['collection', 'puzzle']
defaultMode: 'battle'  // 用户会困惑
```

### 3. 模式配置覆盖

**建议**：只为需要特殊配置的模式提供配置

```typescript
// ✅ 好：只配置需要特殊设置的模式
modeConfig: {
  building: { buildingType: 'castle' },  // 建造城堡而不是塔
  collection: { theme: 'gem' }           // 收集宝石而不是水果
  // racing 和其他模式使用默认配置
}

// ❌ 不必要：为所有模式都提供空配置
modeConfig: {
  building: {},
  collection: {},
  racing: {},
  fishing: {}
}
```

### 4. 题型匹配

**建议**：推荐的模式应该适合题型

```typescript
// ✅ 好：乘法口诀推荐种植、防守模式
{
  generator: { type: 'mulTable' },
  recommendedModes: ['farming', 'defense', 'battle']
}

// ⚠️ 不太合适：乘法口诀推荐解密模式（虽然也能玩，但不是最佳）
{
  generator: { type: 'mulTable' },
  recommendedModes: ['puzzle', 'adventure']
}
```

## 🔄 迁移指南

### 从旧格式迁移到新格式

#### 旧格式（单一模式）

```typescript
{
  id: 'add_1_5',
  // ...
  gameMode: 'building',
  modeConfig: { buildingType: 'tower' }
}
```

#### 新格式（多模式）

```typescript
{
  id: 'add_1_5',
  // ...
  recommendedModes: ['building', 'fishing', 'collection'],
  defaultMode: 'building',
  modeConfig: {
    building: { buildingType: 'tower' }
    // fishing 和 collection 使用默认配置
  }
}
```

### 向后兼容性

如果不修改现有关卡配置，系统会自动处理：

```typescript
// 旧格式关卡
{
  id: 'add_1_5',
  gameMode: 'building'  // 旧字段
}

// 系统自动转换为：
{
  defaultMode: 'building',  // 从 gameMode 获取
  recommendedModes: ['building', 'fishing', 'racing']  // 自动推荐
}
```

## 🛠️ 工具函数

### 获取关卡的默认模式

```typescript
import { getDefaultMode } from '@/lib/levelUtils';

const level = LEVELS.find(l => l.id === 'add_1_5');
const mode = getDefaultMode(level);  // 返回 'building'
```

### 获取推荐模式列表

```typescript
import { getRecommendedModes } from '@/lib/levelUtils';

const level = LEVELS.find(l => l.id === 'add_1_5');
const modes = getRecommendedModes(level);  
// 返回 ['building', 'fishing', 'collection', 'racing']
```

### 获取模式专用配置

```typescript
import { getModeConfig } from '@/lib/levelUtils';

const level = LEVELS.find(l => l.id === 'add_1_5');
const config = getModeConfig(level, 'building');  
// 返回 { buildingType: 'tower' }
```

### 检查模式兼容性

```typescript
import { isModeCompatible } from '@/lib/gameModes/compatibility';

const compatible = isModeCompatible('farming', {
  generatorType: 'mulTable',
  category: '进阶拓展',
  difficulty: 1.6
});
// 返回 true（种植模式适合乘法口诀）
```
