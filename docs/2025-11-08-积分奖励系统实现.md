# 积分奖励系统实现

**日期**: 2025-11-08  
**功能**: 实现关卡积分奖励梯度递增和全对+规定时间内完成才奖励积分的机制

## 📋 需求背景

1. **积分梯度递增**：每个关卡奖励不同的积分，需要设置梯度递增的方式
2. **奖励条件**：只有全对且在规定时间内完成才能奖励积分
3. **目标时间分离**：规定时间和现在的时间上限分开
4. **数据库配置**：所有配置都在数据库中进行配置
5. **答题记录存储**：所有回答记录在数据库中存储

### 3. 奖励逻辑实现

#### 奖励条件
```go
func (s *gameService) calculateRewardPoints(req *dto.SubmitGameRequest, level *model.Level) int {
    // 条件1：必须全对
    if req.CorrectCount != req.TotalQuestions {
        return 0
    }
    
    // 条件2：必须在目标时间内完成
    targetTime := level.TargetTime
    if targetTime == 0 {
        targetTime = level.TimeLimit
    }
    
    if req.TimeUsed > targetTime {
        return 0
    }
    
    // 满足条件，返回奖励积分
    return level.RewardPoints
}
```

#### 奖励判定流程
```
开始游戏
  ↓
完成所有题目
  ↓
检查是否全对？
  ├─ 否 → 不奖励积分
  └─ 是 → 继续
       ↓
检查是否在目标时间内？
  ├─ 否 → 不奖励积分
  └─ 是 → 奖励完整积分
```

## 🎯 奖励机制设计理念

### 1. 梯度递增
- 随着关卡难度增加，奖励积分递增
- 鼓励玩家挑战更高难度的关卡
- 体现关卡价值差异

### 2. 双重条件
- **全对**：确保玩家真正掌握知识点
- **目标时间**：鼓励玩家提高答题速度
- 两个条件缺一不可，提高挑战性

### 3. 时间分离
- **time_limit**：游戏的最大时间限制
- **target_time**：获得奖励的时间要求
- 给玩家更多练习空间，但要获得奖励需要更高要求

### 4. 激励机制
- 基础关卡：目标时间较宽松（80%），降低入门难度
- 进阶关卡：目标时间适中（75%），平衡挑战与可达成性
- 挑战关卡：目标时间严格（70%），体现高难度挑战
