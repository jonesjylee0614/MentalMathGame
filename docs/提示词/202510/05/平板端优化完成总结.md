## 🚀 技术实现要点

### 1. CSS Grid 精准控制
```css
.wrapper {
  display: grid;
  grid-template-rows: auto 1fr auto;
  height: 100vh;
  overflow: hidden;
}

.stage {
  grid-template-columns: 1.4fr 1fr;
}
```

### 2. 高性能动画
- 优先使用 `transform` 和 `opacity`（GPU 加速）
- 避免修改 `width`/`height`（触发重排）
- 使用 `will-change` 提示浏览器优化

### 3. 响应式单位组合
```css
clamp(最小值, 首选值vw/vh, 最大值)
```
- 字号：rem 单位确保可缩放
- 间距：vh 单位适配屏幕高度
- 宽度：vw 单位适配屏幕宽度
