## 需求概述

### 用户反馈的问题

1. **攻击效果不对**  
   需要从左边到右边的子弹飞行动画，像植物大战僵尸一样，多个子弹连续慢慢飞向僵尸

2. **连击位置不对**  
   连击X1弹框挡住了僵尸，需要放到右边一些

3. **答错不够明显**  
   需要让用户清楚知道自己答错了

4. **需要错题清单**  
   旁边最好浮动一个错误题目清单，一道错误一行，默认收起可展开

---

## 实现功能

### ✅ 1. 植物大战僵尸风格子弹系统

**功能描述**：
- 答对题目：植物发射5个绿色子弹，1.2秒慢慢飞向僵尸
- 答错题目：僵尸发射4个橙色子弹，1秒飞向植物
- 子弹有旋转、缩放、发光效果

**视觉效果**：
- 子弹emoji：🟢（植物）/ 🟤（僵尸）
- 半透明圆形背景
- 多层发光阴影
- 动态旋转和缩放

### ✅ 2. 连击徽章位置优化

**问题**：原来在右边遮挡僵尸  
**解决**：移到正中间，植物和僵尸之间，不遮挡任何角色  
**动画**：缩放脉冲，不上下移动

### ✅ 3. 答错反馈大幅增强

**全屏红色遮罩**：
- 透明度85%（原70%）
- 多层渐变效果
- 5次强烈闪烁

**屏幕震动**：
- 幅度±15px（原±10px）
- 逐渐减弱效果
- 持续0.6秒

**错误弹框**：
- 4层阴影（原2层）
- 摇晃动画
- 持续脉冲跳动

### ✅ 4. 错题清单完整功能

**功能特点**：
- 右侧浮动面板
- 默认收起，点击展开
- 显示所有错题详情
- 有错题时脉冲提示
- 响应式适配

## 技术实现详解

### 1️⃣ 子弹系统实现

#### React组件层面

**状态管理**
```typescript
// PlayPage.tsx

const [bullets, setBullets] = useState<number[]>([]);
const [zombieBullets, setZombieBullets] = useState<number[]>([]);
```

**发射逻辑**
```typescript
// 答对时发射植物子弹
if (fb.correct) {
  // 连续发射5个子弹
  [0, 1, 2, 3, 4].forEach((i) => {
    setTimeout(() => {
      setBullets((prev) => [...prev, Date.now() + i]);
    }, i * 200); // 每200ms发射一个
  });
  
  // 2秒后清理
  setTimeout(() => {
    setBullets([]);
  }, 2000);
}

// 答错时发射僵尸子弹
else {
  // 连续发射4个子弹
  [0, 1, 2, 3].forEach((i) => {
    setTimeout(() => {
      setZombieBullets((prev) => [...prev, Date.now() + i]);
    }, i * 180); // 每180ms发射一个
  });
  
  // 1.2秒后清理
  setTimeout(() => {
    setZombieBullets([]);
  }, 1200);
}
```

**JSX渲染（关键！）**
```tsx
{/* 战斗区 */}
```

**关键技术点**：
1. **8个关键帧**：实现平滑飞行轨迹

3. **透明度变化**：模拟发射和爆炸
4. **百分比定位**：适配各种屏幕
5. **GPU加速**：用transform而非left/top（虽然这里用了left/right是为了兼容性）

## 问题与解决

### 🔴 问题1：子弹不显示

**症状**：  
实现了子弹状态和渲染，但页面上看不到子弹

**排查过程**：
1. ✅ React状态更新正常
2. ✅ JSX渲染正常
3. ✅ CSS样式存在
4. ❌ **子弹被遮挡**

**根本原因**：
1. 子弹在 `battleRow`（flex容器）内部
2. flex布局影响了absolute定位
3. 其他元素（characterWrapper）的z-index不明确
4. CSS filter创建了新的层叠上下文

**解决方案**：
1. **将子弹移到battleRow外面**  
   ```tsx
   <section className="battleZone">
     {/* 子弹在这里 - battleRow外面 */}
     {bullets.map(...)}
     
     <div className="battleRow">
       {/* 角色在这里 */}
     </div>
   </section>
   ```

2. **明确z-index层级**  
   ```css
   .bullet { z-index: 100 !important; }
   .comboBadge { z-index: 50; }
   .characterWrapper { z-index: 1; }
   ```

3. **添加isolation**  
   ```css
   .battleZone {
     isolation: isolate;
   }
   ```

4. **确保overflow可见**  
   ```css
   .battleZone {
     overflow: visible !important;
   }
   ```

### 🔴 问题2：连击徽章遮挡角色

**症状**：  
连击徽章在右边，遮挡僵尸头像

**解决方案**：  
改为居中显示
```css
.comboBadge {
  left: 50%;
  transform: translate(-50%, -50%);
}
```

### 🔴 问题3：答错反馈不够明显

**解决方案**：
1. 提高遮罩透明度：70% → 85%
2. 增加闪烁次数：2次 → 5次
3. 加大震动幅度：±10px → ±15px
4. 增强阴影：2层 → 4层
5. 添加持续脉冲动画
