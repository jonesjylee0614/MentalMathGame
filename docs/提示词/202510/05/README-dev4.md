## 🐛 常见问题

### Q1: 题目字体太大/太小？
**A**: 修改 `PlayPage.module.css`:
```css
.questionText {
  font-size: clamp(3rem, 7vw, 5rem);  /* 调整这三个值 */
}
```

### Q2: 动画太快/太慢？
**A**: 修改 `PlayPage.tsx` 中的延迟时间:
```typescript
setTimeout(() => setZombieDamaged(true), 260);  // 调整这个值
```

### Q3: 键盘不工作？
**A**: 确保页面焦点在游戏区域，点击一次页面后再按键盘。

### Q4: 移动端按钮太小？
**A**: 修改 `PlayPage.module.css`:
```css
@media (max-width: 640px) {
  .padButton {
    min-height: 56px;  /* 增大这个值 */
  }
}
```
