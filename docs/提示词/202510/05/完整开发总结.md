**技术实现**：

文件：`src/components/Layout.tsx`

**效果**：
- 平板设备屏幕利用率提升30%+

### 三、用户体验提升 (1小时)

#### 3.1 键盘快捷键支持 ⌨️

**问题**：只能用鼠标点击按钮，效率低。

**解决方案**：完整的键盘快捷键系统

**技术实现**：

文件：`src/routes/PlayPage.tsx`
```typescript
useEffect(() => {
  const handleKeyDown = (e: KeyboardEvent) => {
    if (state !== 'playing') return;
    
    // 数字键 0-9
    if (e.key >= '0' && e.key <= '9') {
      handleNumberClick(e.key);
      e.preventDefault();
    }
    // Enter 提交
    else if (e.key === 'Enter' && answer.trim()) {
      handleSubmit();
      e.preventDefault();
    }
    // Backspace 删除
    else if (e.key === 'Backspace') {
      handleDelete();
      e.preventDefault();
    }
    // Escape 清空
    else if (e.key === 'Escape') {
      handleClear();
      e.preventDefault();
    }
    // 减号
    else if (e.key === '-') {
      handleNumberClick('-');
      e.preventDefault();
    }
  };

  window.addEventListener('keydown', handleKeyDown);
  return () => window.removeEventListener('keydown', handleKeyDown);
}, [state, answer, ...]);
```

**快捷键清单**：
- `0-9`：输入数字
- `Enter`：提交答案
- `Backspace`：删除最后一位
- `Escape`：清空输入
- `-`：输入负号

**效果**：
- 答题速度显著提升
- 键盘用户友好
- 游戏流畅度增强

### 四、性能与无障碍优化 (30分钟)

#### 4.1 GPU加速优化 ⚡

**问题**：大量动画可能导致卡顿。

**解决方案**：使用 `will-change` 提示浏览器优化

**技术实现**：

文件：`src/styles/PlayPage.module.css`
```css
.character {
  will-change: transform;
}

.hpFill {
  will-change: width;
}

.numButton {
  will-change: transform, box-shadow;
}
```

**效果**：
- 动画帧率提升
- GPU提前分配资源
- 低端设备表现改善

---

#### 4.2 动画减弱支持 ♿

**问题**：用户可能患有前庭疾病，动画引起不适。

**解决方案**：支持 `prefers-reduced-motion`

**技术实现**：

文件：`src/styles/global.css`
```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

**效果**：
- 尊重用户系统设置
- 无障碍支持完善
- 降低引起不适的风险

## 💡 开发经验总结

### 最佳实践

1. **渐进式开发**
   - 先完成核心功能
   - 再优化细节
   - 最后打磨体验

2. **模块化设计**
   - 组件职责单一
   - 样式隔离清晰
   - 便于维护扩展

3. **用户优先**
   - 响应式优先
   - 无障碍支持
   - 性能优化

4. **文档驱动**
   - 及时记录
   - 详细注释
   - 便于交接

### 遇到的挑战

1. **动画冲突**
   - 问题：多个动画同时触发时冲突
   - 解决：使用状态管理，控制动画时序

2. **性能优化**
   - 问题：大量动画导致卡顿
   - 解决：GPU加速，will-change优化

3. **响应式布局**
   - 问题：不同屏幕下布局断裂
   - 解决：多断点测试，渐进增强

4. **键盘事件**
   - 问题：事件监听器内存泄漏
   - 解决：正确清理事件监听器
