## ⚡ 动画优化

### 动画速度对比

| 动画类型 | 优化前 | 优化后 | 改进 |
|---------|--------|--------|------|
| 题目入场 | 500ms linear | 400ms cubic-bezier | 更有弹性 |
| HP掉血 | 450ms ease | 350ms ease | 更快反馈 |

| 连击光晕 | 1200ms | 1000ms | 更活跃 |

### 新增动画效果

✅ **倒计时临界脉动**
- 条件：剩余时间 ≤10秒
- 效果：0.6s 快速缩放 + 红色光晕

✅ **能量条攻击动画**
- 触发：答对/答错
- 效果：Y轴拉伸 1.2倍 + 亮度闪烁

✅ **输入框焦点光晕**
- 触发：点击输入框
- 效果：4px 外围橙色光圈

## 💬 文案动态化

### 智能激励系统

```typescript
条件 → 文案
━━━━━━━━━━━━━━━━━━━━━━━━
剩余 0 题          →  "最后冲刺！"

连击 ≥3           →  "完美连击！保持节奏！"
怪兽HP ≤30%       →  "怪兽快被打败了！"
玩家HP ≤30%       →  "小心！继续加油！"
其他              →  "还有 N 题，继续战斗！"
```

### 文案应用位置

1. **题目区顶部** - 替代静态"打败僵尸！"
2. **底栏中央** - 替代"再答N题就能赢"
3. **动态更新** - 随游戏状态实时变化

### 达成标准

| 指标 | 目标 | 实际 | 状态 |
|-----|------|------|------|
| FPS | ≥55 | ~60 | ✅ |
| 反馈延迟 | <300ms | 150-400ms | ✅ |

| 触控区 | ≥48px | ≥56px | ✅ |
| 上手时间 | <3s | <3s | ✅ |

### 性能优化技巧

1. **GPU 加速**
   - 优先使用 `transform` / `opacity`
   - 避免修改 `width` / `height`

2. **动画优化**
   - 使用 `will-change` 提示
   - 控制同时播放的动画数量

3. **布局稳定**
   - Grid 固定高度 (100vh)
   - 避免动态高度计算

## 💡 设计理念

### 三大核心原则

1. **视觉焦点统一**
   - 题目 = 视觉中心
   - 左答题 / 右反馈
   - 一眼看清所有信息

2. **操作节奏流畅**
   - 大按钮 = 快速点击
   - 即时反馈 = 不等待
   - 动画流畅 = 不卡顿

3. **动效引导自然**
   - 答对 → 攻击 → 怪兽掉血
   - 答错 → 反击 → 我方掉血
   - 连击 → 光晕 → 激励文案
