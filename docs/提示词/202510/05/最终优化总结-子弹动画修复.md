## 🎯 用户需求

### 原始需求
1. **攻击效果不对** - 需要从左边到右边的子弹飞行动画，像植物大战僵尸一样，多个子弹连续慢慢飞向僵尸
2. **连击位置不对** - 连击X1弹框遮挡僵尸，需要放到右边一些
3. **答错不够明显** - 需要让用户清楚知道自己答错了
4. **错题清单** - 旁边最好浮动一个错误题目清单，一道错误一行，默认收起可展开

## 🚀 实现方案

### 1️⃣ 子弹飞行动画系统

#### 问题诊断过程

**初始问题**：子弹没有显示
**排查步骤**：
1. 检查React状态更新 ✅ 正常
2. 检查JSX渲染 ✅ 正常
3. 检查CSS定位 ❌ **发现问题**

**根本原因**：
- 初始位置不明确（`left: 0` 或 `right: 0`）
- `battleRow` 容器没有明确的尺寸
- z-index 不够高，被其他元素遮挡
- CSS动画的百分比定位可能计算错误

#### 最终解决方案

##### React组件层面
```typescript
// PlayPage.tsx

// 状态管理
const [bullets, setBullets] = useState<number[]>([]);
const [zombieBullets, setZombieBullets] = useState<number[]>([]);

// 答对时发射植物子弹
if (fb.correct) {
  [0, 1, 2, 3, 4].forEach((i) => {
    setTimeout(() => {
      setBullets((prev) => [...prev, Date.now() + i]);
    }, i * 200); // 每200ms发射一个
  });
  
  setTimeout(() => setBullets([]), 2000); // 2秒后清理
}

// 答错时发射僵尸子弹
else {
  [0, 1, 2, 3].forEach((i) => {
    setTimeout(() => {
      setZombieBullets((prev) => [...prev, Date.now() + i]);
    }, i * 180); // 每180ms发射一个
  });
  
  setTimeout(() => setZombieBullets([]), 1200); // 1.2秒后清理
}

// JSX渲染
{bullets.map((id) => (
  <div key={id} className={styles.bullet}>🟢</div>
))}
{zombieBullets.map((id) => (
  <div key={id} className={styles.zombieBullet}>🟤</div>
))}
```

#### 关键技术点

1. **位置管理**
   - 植物子弹：`left: 10%` → `left: 90%`
   - 僵尸子弹：`right: 10%` → `right: 90%`
   - 使用百分比确保响应式

2. **动画细节**
   - 8个关键帧实现平滑过渡
   - 旋转+缩放增加动感
   - 透明度变化模拟发射和爆炸

3. **性能优化**
   - `will-change` 提示浏览器优化
   - `transform` 和 `opacity` 触发GPU加速
   - 使用CSS动画而非JS动画

4. **层级控制**
   - 子弹 `z-index: 100` 最高
   - 连击徽章 `z-index: 15` 中等
   - 角色 `z-index: 1` 默认

##### React实现
```typescript
// PlayPage.tsx

// 状态
const [errorListOpen, setErrorListOpen] = useState(false);

// 获取错题列表
const wrongAnswers = snapshot?.history.filter(h => !h.correct) || [];

// JSX
{state === 'playing' && (
  <div className={styles.errorPanel}>
    {/* 收起时显示按钮 */}
    {!errorListOpen && (
      <button
        className={`${styles.errorToggle} ${wrongAnswers.length > 0 ? styles.hasErrors : ''}`}
        onClick={() => setErrorListOpen(true)}
      >
        ❌ 错题 {wrongAnswers.length > 0 && `(${wrongAnswers.length})`}
      </button>
    )}
    
    {/* 展开时显示面板 */}
    {errorListOpen && (
      <div className={styles.errorList}>
        <div className={styles.errorListHeader}>
          <span className={styles.errorListTitle}>❌ 错题清单</span>
          <span className={styles.errorCount}>{wrongAnswers.length}</span>
          <button onClick={() => setErrorListOpen(false)}>×</button>
        </div>
        
        {wrongAnswers.length === 0 ? (
          <div className={styles.emptyMessage}>
            🎉 太棒了！<br />还没有错题
          </div>
        ) : (
          <div className={styles.errorItems}>
            {wrongAnswers.map((item, idx) => {
              const q = Game.questions?.find(qu => qu.id === item.id);
              return (
                <div key={`${item.id}-${idx}`} className={styles.errorItem}>
                  <div className={styles.errorQuestionText}>
                    {q?.text || '题目'}
                  </div>
                  <div className={styles.errorAnswerRow}>
                    <div className={styles.yourAnswerWrong}>
                      你的答案：{item.answer || '空'}
                    </div>
                    <div className={styles.correctAnswerShow}>
                      ✓ 正确答案：{item.expected}
                    </div>
                  </div>
                </div>
              );
            })}
          </div>
        )}
      </div>
    )}
  </div>
)}
```

## 🔧 技术实现亮点

### 1. CSS动画优化
- **使用GPU加速**：所有动画用 `transform` 和 `opacity`
- **性能提示**：`will-change` 告诉浏览器优化方向
- **缓动函数**：`ease-out` 让动画自然减速
- **多帧控制**：8个关键帧实现平滑过渡

### 2. React状态管理
- **时间戳作为key**：确保每个子弹唯一
- **定时清理**：动画结束后自动清理DOM
- **错题数据**：从游戏引擎的history直接获取

### 3. 响应式设计
- **clamp()函数**：自适应字体和间距
- **媒体查询**：针对桌面/平板/手机三种布局
- **百分比定位**：确保子弹在各屏幕正常飞行

### 4. 视觉层次
```
z-index层级：
- 200：错题面板（最高）
- 100：子弹（高）
- 99：全屏遮罩
- 15：连击徽章
- 10：角色动画
- 3：顶部栏/底部栏
- 2：战斗区
- 1：题目区
```
