# 心算勇士 (Mental Math Arena) - 完整技术文档

## 项目概述

心算勇士是一款基于 React + TypeScript + Vite 构建的心算训练游戏，采用 PVE 战斗模式，玩家通过解答数学题目来攻击敌人。项目采用模块化架构设计，具有良好的可扩展性和维护性。

## 技术栈

- **前端框架**: React 18
- **开发语言**: TypeScript
- **构建工具**: Vite
- **路由管理**: React Router v6
- **样式方案**: CSS Modules
- **状态管理**: React Context API
- **数据持久化**: LocalStorage

## 核心模块详解

### 1. 游戏引擎 (engine.ts)

游戏引擎是整个应用的核心，负责管理游戏状态、处理游戏逻辑和事件分发。

**主要功能**:
- 游戏状态管理（idle、preparing、playing、result）
- 题目生成与校验
- 战斗逻辑计算（HP、伤害、连击）
- 得分计算
- 事件系统（基于发布-订阅模式）

**关键方法**:
```typescript
- init(level: LevelConfig): void        // 初始化游戏
- start(): void                         // 开始游戏
- submit(answer: string): void          // 提交答案
- reset(): void                         // 重置游戏
- on(event, handler): Unsubscribe      // 订阅事件
```

**事件类型**:
- `statechange`: 游戏状态变化
- `question`: 新题目生成
- `feedback`: 答题反馈
- `update`: 游戏数据更新
- `finish`: 游戏结束

### 2. 题目生成器 (generators.ts)

题目生成器负责根据关卡配置生成各类数学题目。

**支持的题型**:
- 加法运算（单步/多步）
- 减法运算（单步/多步）
- 乘法运算
- 除法运算
- 混合运算

**生成策略**:
- 根据难度系数动态调整数值范围
- 支持进位、退位等特殊规则
- 保证题目有效性（如除法无余数）

### 3. 关卡系统 (levels.ts)

关卡系统提供预设的游戏关卡配置。

**关卡配置参数**:
```typescript
{
  id: string              // 关卡唯一标识
  name: string            // 关卡名称
  desc: string            // 关卡描述
  category: string        // 关卡分类
  difficulty: number      // 难度系数 (0-10)
  count: number           // 题目数量
  timeSec: number         // 时间限制（秒）
  hp?: {                  // 生命值配置
    player: number
    monster: number
  }
  generator: () => Question  // 题目生成器
}
```

**关卡分类**:
- 加法专区
- 减法专区
- 乘法专区
- 除法专区
- 综合挑战

### 4. 状态管理 (GameContext.tsx)

使用 React Context API 实现全局状态管理。

**管理的状态**:
- `profile`: 用户信息（名称、创建时间）
- `settings`: 游戏设置（音效、震动、字体等）
- `progress`: 关卡进度
- `stats`: 统计数据（总分、正确率、连击等）
- `lastResult`: 最近一次游戏结果

**持久化**:
所有状态通过 LocalStorage 持久化存储，键名为 `mental-math-arena-*`。

### 5. 响应式布局系统

**桌面端 (> 1024px)**:
- 左侧固定导航栏
- 主内容区域占据剩余空间
- 游戏页面采用左右分栏布局

**平板端 (768px - 1024px)**:
- 隐藏左侧导航栏
- 底部显示固定导航栏
- 游戏页面改为单列布局

**移动端 (< 768px)**:
- 底部导航栏
- 所有内容单列展示
- 适配小屏幕的字体和间距

4. **响应式设计**: 适配各种屏幕尺寸

## 数据流向

### 游戏流程

```
用户选择关卡 
  ↓
初始化游戏引擎 (Game.init)
  ↓
开始游戏 (Game.start)
  ↓
生成题目 → 显示题目
  ↓
用户输入答案
  ↓
提交答案 (Game.submit)
  ↓
校验答案 → 计算伤害 → 更新HP
  ↓
生成下一题 / 游戏结束
  ↓
记录结果 → 更新统计数据
  ↓
跳转结果页
```

### 状态更新流程

```
用户操作
  ↓
Context API 更新状态
  ↓
localStorage 持久化
  ↓
组件重新渲染
```

## 性能优化

1. **React.memo**: 对部分组件进行记忆化
2. **useCallback**: 缓存事件处理函数
3. **useMemo**: 缓存计算结果
4. **CSS Modules**: 样式隔离，避免全局污染
5. **懒加载**: 路由级别的代码分割（可扩展）

## 可扩展性设计

### 添加新关卡

在 `levels.ts` 中添加新的关卡配置：

```typescript
{
  id: 'new-level',
  name: '新关卡',
  desc: '关卡描述',
  category: '分类名称',
  difficulty: 5,
  count: 10,
  timeSec: 60,
  generator: () => {
    // 自定义题目生成逻辑
    return { text: '题目', answer: 42 };
  }
}
```

### 添加新题型

在 `generators.ts` 中实现新的生成器函数：

```typescript
export function generateNewType(): Question {
  // 题目生成逻辑
  return {
    text: '题目内容',
    answer: 答案
  };
}
```

### 扩展设置项

在 `GameContext.tsx` 的 `Settings` 类型中添加新字段，并更新默认值。

## 部署说明

### 构建

```bash
npm run build
```

生成的静态文件在 `dist/` 目录下。

### 部署方式

- **静态托管**: 可部署到 Vercel, Netlify, GitHub Pages
- **服务器**: 使用 Nginx/Apache 托管静态文件
- **CDN**: 推荐使用 CDN 加速资源加载

### 环境变量

项目不依赖环境变量，所有配置在代码中定义。

## 开发建议

### 代码规范

- 使用 TypeScript 严格模式
- 遵循 React Hooks 规则
- CSS Modules 命名使用小驼峰
- 组件使用函数式组件

### 调试技巧

1. 使用 React DevTools 查看组件状态
2. 在浏览器控制台检查 localStorage 数据
3. 使用游戏引擎的事件监听进行调试

```typescript
Game.on('update', (snapshot) => {
  console.log('游戏状态:', snapshot);
});
```
